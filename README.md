# Snap

开源的 macOS 截图工具，参考 iShot Pro 的交互：快捷键截图、标注、OCR、贴图、长截图。另外加了**原位翻译**：识别截图里的外文，用大模型翻译后直接画回原文的位置。

- OCR 使用系统自带的 Vision 框架，在本机完成。
- 翻译使用 OpenAI 兼容接口，默认是 DeepSeek 的 `deepseek-flash`。只发送识别出的文字，截图本身不上传。
- 纯 Swift 编写，没有第三方依赖。要求 macOS 14 或更高版本。

## 构建

只需要安装 Command Line Tools，不需要 Xcode。

```bash
scripts/build-app.sh      # 生成 build/Snap.app
open build/Snap.app
scripts/test.sh           # 运行单元测试
```

如果钥匙串里有 `Apple Development` 证书，构建脚本会自动用它签名，也可以通过 `SIGN_IDENTITY` 指定。屏幕录制权限和签名绑定：用 ad-hoc 签名时，每次重新构建后系统可能会再次请求权限。

## 使用

首次启动时，请在「系统设置 → 隐私与安全性 → 屏幕与系统录音」中允许 Snap，然后重新打开它。

**选区**

| 操作 | 方式 |
| --- | --- |
| 开始截图 | `⌥A`（可在设置中修改），或点菜单栏图标 |
| 超级截图 | 在设置里开启后，按住 `⌥⌘` 在任何地方直接拖动，松开就进入截图并选好这块区域，不用先按快捷键。需要辅助功能权限 |
| 延时截图 | 菜单栏 Snap → 延时截图 → 3 / 5 / 10 秒后。菜单栏图标旁显示倒计时，这段时间可以打开菜单、悬停出提示再截；可从菜单取消 |
| 框选 | 拖拽；按住 `⇧` 锁定 1:1 |
| 选窗口 / 全屏 | 单击光标下高亮的窗口；什么都没指到时单击选中整个屏幕 |
| 选界面元素 | 授予辅助功能权限后，高亮的是光标下的按钮、输入框、列表、工具栏等；滚轮向上切换到外层元素（最外是窗口），向下回到内层；`Tab` 在「界面元素」和「只识别窗口」之间切换。可在设置里关闭 |
| 放大镜 | 选区时自动出现，显示坐标和像素颜色；`C` 复制颜色，`⇧` 在 HEX 和 RGB 之间切换 |
| 像素级定位 | 选区前 `←↑↓→` 移动光标 1pt（按住 `⇧` 每次 10pt） |
| 调整选区 | 拖动控制点；拖动选区内部移动；`←↑↓→` 移动 1pt，`⌘` + 方向键扩展对应的边，`⇧` + 方向键收缩对应的边 |
| 输入尺寸 | 点选区上方蓝条里的尺寸，输入 `1280x720`（也可以用 `×`、`*`、逗号或空格分隔）回车 |
| 锁定比例 | 蓝条里的比例按钮：每点一次切换 自由 → 1:1 → 4:3 → 3:4 → 16:9 → 9:16 → 3:2 → 2:3。锁定后框选和拖动控制点都保持比例，下次截图仍然记得 |
| 鼠标指针 | `` ` ``：把截图开始时的鼠标指针加进截图或去掉；设置里可以改成默认包含 |
| 刷新截图 | `F5` 或 `⌘R`：重新截取当前屏幕，保留选区和标注，适合等动画、加载完成后再截 |
| 上次选区 | `R` |
| 截图历史 | `,` 回看上一张截图，继续按 `,` 往前、`.` 往回，回到最后就是当前屏幕。历史里的选区和标注都还在，可以接着编辑、复制、贴图；菜单栏 Snap → 回放上一次截图 也能直接打开 |

**标注**

| 操作 | 方式 |
| --- | --- |
| 工具 | 矩形 `R`、椭圆 `O`、直线 `L`、箭头 `A`、画笔 `P`、记号笔 `H`、马赛克 `M`、橡皮擦 `E`、放大镜 `G`、文字 `T`、序号 `N` |
| 约束 | 按住 `⇧`：正方形、正圆、45° 直线和箭头、画笔画直线、记号笔画水平/垂直/45° 直线 |
| 放大镜 | `G`：从要放大的地方拖出一个圈，旁边出现 2 倍放大的镜头并用线连起来；两个圈都能单独拖动 |
| 折线 | 直线或箭头工具下单击（而不是拖动）开始折线，每次单击加一个拐点；双击、右键、`Return` 或 `Esc` 结束。箭头工具的折线在最后一段画箭头。选中后可以拖动每个拐点 |
| 记号笔 | 半透明的荧光笔，叠在文字上文字依然清楚；同一笔重叠的地方不会变深 |
| 编辑已有标注 | 点中即可选中；拖动移动，拖控制点改大小或端点；`⌫` 删除；`←↑↓→` 微调（`⇧` 每次 10pt） |
| 粗细和字号 | 样式条选择，或滚动鼠标滚轮微调，对选中的标注同样有效 |
| 样式 | 样式条里：矩形、椭圆、直线、箭头、画笔可选实线 / 虚线 / 点线；矩形可切换圆角；箭头可选实心、线条或双向；文字可选普通、加底色（自动配黑或白字）或描边。对选中的标注同样有效，每种工具记住自己的选择 |
| 颜色 | 每种工具分别记住自己的颜色和粗细（记号笔默认黄色），重启后仍然保留；`⌥` + 滚轮调颜色的不透明度（10% 一档），换色时保留不透明度 |
| 马赛克 | 画笔涂抹或框选区域；效果可选格子或毛玻璃 |
| 橡皮擦 | 画笔涂抹或框选区域，把那里恢复成原始截图，擦掉下面的标注；擦除本身也可以撤销、移动 |
| 文字 | 支持多行（回车换行）；`Esc`、`⌘↩` 或点击别处完成；双击已有文字再编辑 |
| 序号 | 自动递增，删除后自动重排 |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` |

**识别、翻译与输出**

| 操作 | 方式 |
| --- | --- |
| OCR | `X`：识别文字并复制，在旁边显示可编辑的结果，同时在图上标出识别到的文字 |
| 翻译 | `Y`：把译文画回原位；再按一次切换原文和译文；按住 `⌥` 临时查看原文 |
| 复制 | `Return`、`⌘C` 或双击选区 |
| 保存 | `⌘S` 直接保存到设置里的文件夹（默认 `~/Pictures/Snap`）；`⇧⌘S` 另存为 |
| 打印 | 截图中或贴图上 `⌘P`（贴图右键也有「打印…」），自动缩放到一页并居中 |
| 分享 | 工具栏的分享按钮：关闭截图后弹出系统分享菜单（隔空投送、邮件、信息、备忘录等），贴图右键也有「分享…」 |
| 贴图 | `⌘T`：把选区（含标注和译文）钉在屏幕原来的位置 |
| 长截图 | `S`：在选区里滚动，自动拼接成长图 |
| 后退一步 / 退出 | `Esc` 逐级后退：提交文字 → 关闭 OCR 面板 → 取消选中 → 放下工具 → 退出截图；右键同理，但有标注时不会退出 |

**白板**：菜单栏 Snap → 白板 / 透明白板。白板是一整屏白纸；透明白板不冻结屏幕，直接在当前画面上画，适合演示和共享屏幕讲解。进入时已选好画笔；空格显示/隐藏工具栏；连按两次 `Esc` 退出，防止误关。透明白板复制或保存时会截取当时的屏幕，再把画的内容叠上去。

**扫码**：菜单栏 Snap → 扫描屏幕上的二维码 / 条形码（可在设置里绑定快捷键）。直接识别所有屏幕上的码并复制内容；是网址时可以一键在浏览器打开。截图时按 `X` 识别文字也会顺带识别选区里的码。

选区上方的蓝色条可以调整圆角，也可以开关阴影，导出时生效。

**贴图**

| 操作 | 方式 |
| --- | --- |
| 从剪贴板贴图 | `⌥⇧V`（可在设置中修改或清除），或菜单栏 Snap → 从剪贴板贴图。能贴的内容：图片；访达里复制的图片文件（多张会依次错开）；颜色值（`#FF8000`、`rgb(255,128,0)`、`255, 128, 0`）会贴成色卡；网页或文档里复制的富文本；纯文本（代码、JSON 自动用等宽字体）；其他文件贴出路径 |
| 复制文字 | `⇧⌘C`：文字、颜色、文件贴图可以把原始文字复制回来 |
| 移动 | 拖动；方向键移动 1pt，按住 `⇧` 每次 10pt；按住 `⇧` 拖动时吸附到其他贴图、窗口和屏幕边缘 |
| 多选 | `⌘` + 单击逐个选中，`⌘A` 选中所有可见贴图；之后拖动、`⌥` + 滚轮调透明度、`⌘W` 关闭都作用于全部选中的贴图 |
| 拖入图片 | 把图片文件、图片或网页里的图片链接拖到贴图上，替换贴图内容（链接会自动下载，最大 20MB） |
| 缩放 / 透明度 | 滚轮以光标为中心缩放（10% 到 800%），或 `=` / `-`；`⌥` + 滚轮调透明度；`0` 或中键恢复 100% |
| 旋转 / 翻转 | `1` 顺时针、`2` 逆时针旋转 90°；`3` 水平翻转、`4` 垂直翻转（和 Snipaste 相同） |
| 复制 / 保存 | `⌘C` / `⌘S` |
| 关闭 | 双击、`Esc` 或 `⌘W`；菜单栏里可以恢复最近关闭的 10 张 |
| 灰度 / 反色 | `5` 切换灰度，`6` 切换反色（和 Snipaste 相同）；复制、保存、分享得到的也是显示的效果 |
| 透明区域 | 右键 → 透明区域：带透明通道的图片可以改成浅色或深色棋盘格背景 |
| 缩略图 | `⇧` + 双击：收成 64pt 的小方块（以双击处为中心）；右键拖出一个框：只留下框里的部分。双击恢复原样，位置不变；右键 → 裁剪为此区域 则永久裁掉其余部分 |
| 标注 | 空格或右键 → 标注…：在贴图上用截图的全部工具标注（包括识别文字和翻译）；✓ 或回车完成，`⌘C` / `⌘S` 完成的同时复制 / 保存，`Esc` 放弃。标注时贴图临时回到 100%，完成后恢复原来的缩放 |
| 分组 | 菜单栏 Snap → 贴图分组：新建、切换、重命名、删除分组。只显示当前分组的贴图，适合按项目或科目分开放；贴图右键 → 移到分组 |
| Solo | 贴图右键 → Solo：只显示这一张，其他贴图暂时隐藏；再选一次恢复 |
| 销毁 | `⇧Esc`：关闭且不进入恢复列表，适合确定不再需要的贴图 |
| 隐藏 / 显示全部 | `⌥⇧H`（可在设置中修改或清除），或菜单栏 Snap → 隐藏全部贴图。隐藏不等于关闭：贴图仍然保留，再按一次就回来 |
| 右键菜单 | 识别文字、缩放、透明度、旋转、翻转、鼠标穿透、始终置顶、关闭全部 |

退出 Snap 时贴图会保留下来（位置、缩放、透明度、分组都记得），下次启动自动恢复；不需要的话可以在设置里关掉。

边框颜色表示状态：蓝色是当前贴图，灰色是其他贴图，绿色表示已开启鼠标穿透。开启穿透后，贴图不再响应鼠标，需要从菜单栏 Snap → 取消贴图的鼠标穿透 恢复。

**长截图**

框选要滚动的区域后按 `S`。截图遮罩会关闭，选区外面留一圈蓝色虚线框，旁边出现控制面板。在框里正常滚动鼠标或触控板，Snap 会自动拼接，面板里实时显示预览和高度。点「完成」后可以查看整张长图，然后复制、保存或贴图。

- 固定的导航栏和底部工具栏只会出现一次，不会在长图里重复。
- 「自动滚动」会匀速往下滚，滚到底自动停止。这个功能需要辅助功能权限。
- 框选时避开滚动条效果更好；滚得太快、两帧之间没有重叠时，面板会提示放慢速度。
- 长度上限是 60,000 像素。

## 自动化

其他程序、脚本、快捷指令、Raycast / Alfred 可以用 `snap://` 链接控制 Snap：

| 链接 | 作用 |
| --- | --- |
| `snap://capture` | 开始截图；加 `output=clipboard,pin,save` 后，选好区域立即输出，不再停留 |
| `snap://capture?area=full` | 静默截取光标所在屏幕（默认复制）；`area` 也可以是 `last`（上次选区）、`window`（当前窗口）或 `x,y,宽,高`（以主屏左上角为原点的点坐标） |
| `snap://capture?area=window&file=~/Desktop/w.png&delay=2` | 2 秒后截取当前窗口并保存到指定文件 |
| `snap://pin` · `snap://toggle-pins` · `snap://whiteboard?transparent=1` · `snap://scan` · `snap://history` | 剪贴板贴图 · 隐藏/显示贴图 · 透明白板 · 扫码 · 回放上一次截图 |

**快捷键命令**：设置 → 快捷键命令 里可以给任意命令绑定全局快捷键，内置常用预设（截取全屏并复制、截取上次区域、截取当前窗口、截图后直接贴图、延时截图、白板、回放、下一个贴图分组等），也可以自己写 `snap://` 链接或下面的命令行。「忽略这些应用」里的应用（填应用名、Bundle ID 或路径片段）在前台时，Snap 的所有快捷键暂时失效，按键原样交给它们，适合游戏和远程桌面。

命令行兼容 Snipaste 的常用写法，会转发给正在运行的 Snap（加 `--dry-run` 只打印对应的链接）：

```bash
/Applications/Snap.app/Contents/MacOS/Snap snip --full -o clipboard
/Applications/Snap.app/Contents/MacOS/Snap snip --area 0 0 800 600 -o "pin;quick-save;~/Desktop/a.png"
/Applications/Snap.app/Contents/MacOS/Snap snip --last --delay 1.5
/Applications/Snap.app/Contents/MacOS/Snap paste | toggle-images | whiteboard [--transparent] | barcode-scan
```

## 设置

菜单栏 Snap → 设置 里可以修改截图和贴图的快捷键、保存位置和格式，开关截图音效，以及设置登录时启动。

- **截图历史**：默认保留最近 20 张（0 为关闭），可选「按 Esc 取消的截图也保留」，防止误按 Esc 丢掉刚做好的标注。保存在本机 `~/Library/Application Support/Snap/History`，可以一键清空。
- **文件名**：默认 `Snap {yyyy-MM-dd HH.mm.ss}`。`{app}` 换成截图时位于前台的应用名，大括号里的其他内容按日期格式展开，例如 `{app}_{yyyyMMdd_HHmmss}` → `Safari_20260925_153000.png`。重名时自动加序号。
- **复制或贴图时也自动保存**：复制和贴图的同时，把图片按上面的文件名存到保存位置，方便事后找回。
- **复制图片时同时复制为文件**：开启后，复制的图片同时带一个 PNG 文件，在访达里 `⌘V` 就能粘贴成文件，在聊天窗口粘贴仍然是图片。个别聊天软件会因此把图片当作文件发送，所以默认关闭。临时文件放在 `~/Library/Caches/app.snap.Snap/Clipboard`，一天后自动清理。

## 翻译设置

菜单栏 Snap → 设置：

- **Base URL**：默认 `https://api.deepseek.com`。任何 OpenAI 兼容服务都可以用。
- **模型**：默认 `deepseek-flash`。
- **API Key**：保存在钥匙串中。
- **译成**：简体中文（默认）、繁體中文、English、日本語、한국어。

填好后可以点「测试连接」检查配置。

## 开发

```
Sources/SnapCore/   纯逻辑，有单元测试：Vision 坐标换算、段落合并、取色、翻译接口与缓存
Sources/Snap/       应用：截图覆盖层、标注、工具栏、OCR、译文排版、导出、设置
```

不打开截图界面也能检查 OCR 和翻译排版：

```bash
DEEPSEEK_API_KEY=sk-… .build/debug/Snap --translate-image input.png output.png --scale 2
```

不设置 Key 时会用占位译文，只检查排版效果。

不打开真实的截图界面也能检查交互：下面的命令会离屏创建截图视图，用模拟的鼠标和键盘事件走一遍选区、标注、编辑、撤销、OCR 等步骤，每一步输出一张 PNG。

```bash
.build/debug/Snap --ui-demo background.png out/
```

需要 AppKit 的功能（贴图窗口、剪贴板、渲染）有一组脚本化的自检，逐条输出 PASS / FAIL，有失败时退出码非零：

```bash
.build/debug/Snap --check all          # 或者只跑一项，例如 --check pins-hide
```

长截图的端到端测试会在屏幕上打开一个带固定页眉的长列表窗口，自动滚动并截图拼接，最后导出结果。这个测试需要运行它的终端有屏幕录制权限。另一个命令用来诊断两帧为什么没有接上：

```bash
.build/debug/Snap --scroll-demo long.png
.build/debug/Snap --stitch-diagnose frame1.png frame2.png
```

同一个可执行文件第一次调用 Vision 识别时，系统要编译一次识别模型，可能需要几十秒；之后就很快。应用启动时会在后台预热一次。
